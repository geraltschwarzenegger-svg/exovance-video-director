# Работа с Exovance Video Director

Пиши пользователю по-русски. Для задания на видео прочитай [SKILL.md](SKILL.md) и выбери нужные инструкции в [references](references/). При незнакомой ситуации используй [правила для неполного брифа](references/edit-decisions.md). Выполняй доступные монтаж, звук, анимацию и экспорт самостоятельно.

При точечной замене сохраняй остальной монтаж. Используй исходное время и место заменяемой подписи, если они понятны. Для новой подписи уточняй только недостающее время или место, если выбор не делегирован. Исключай дубли `Exovance`. Спорное слово покажи с таймкодом и местом, затем продолжай независимую часть работы.

Для мягкого движения отдельной подписи используй пресет `--effect soft-glint --fade 0.6`. При замене белой надписи внутри титра сравни с соседними словами размер, толщину, отступы, цвет, свечение и движение. Для поиска краткой надписи запускай OCR на отрезке через `--frames-from` и `--frames-to`.

Начинай с проверки источника. Для сложной маски или анимации сначала собери пробный фрагмент. Заверши проверкой реального MP4, включая ориентацию, положение подписи, тайминг и звук. По умолчанию целевой формат — 1080p и 60 FPS с сохранением пропорций. Оригиналы и рендеры оставляй в рабочих папках за пределами коммитов.

При изменении скриптов запусти `python tests/smoke_test.py`. Проверка использует синтетические ролики и покрывает OCR по отрезку, 60 FPS, звук, ориентацию, движение и блик подписи.
