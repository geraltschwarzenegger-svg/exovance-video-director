# Инструменты и источники

Проверено 15.11.2026 по официальным страницам и README. Перед использованием меняющегося API перепроверять. Заявленная разработчиком функция не равна нашей проверке в установленном приложении.

## Основной бесплатный путь

[Стек для ChatGPT/Codex](gpt-video-stack.md) — приоритеты для монтажа, покадровой анимации, трекинга и звука. Подбирать инструмент под правку, проверять доступность в рабочей среде и самостоятельно доводить задачу до рендера.

FFmpeg/ffprobe: https://ffmpeg.org/ffmpeg-filters.html — кадры, склейки, xfade/acrossfade, overlay/drawtext, звук, loudnorm, sidechaincompress, atempo, экспорт. Проверять текущие параметры фильтров.

Вспомогательные скрипты: media_audit.py даёт метаданные, кадры и кандидаты музыкальных атак; watermark_export.py — одиночную подпись, тайминг, предварительный кадр и контролируемую обрезку. Они не заменяют творческий монтаж.

## Storytold / ArtCraft

https://github.com/storytold . Проекты ниже по README dual-licensed MIT/Apache-2.0; встроенные материалы и торговые марки могут иметь другие условия.

| Проект | Назначение | Интеграция по README | Ограничение |
|---|---|---|---|
| [FilmCraft](https://github.com/storytold/filmcraft) | Монтаж, цвет, титры, звук, экспорт | filmcraft-cli commands/mcp, JSON control, OTIO/FCPXML/AAF/EDL | Alpha; авторы отмечают ограничения реальных медиа, плагинов и кодеков |
| [EffectCraft](https://github.com/storytold/effectcraft) | Моушн, маски, композитинг, 3D | effectcraft-cli mcp/render, JSON control | Alpha; пока не рекомендуется авторами для production client work; не все UI-команды headless |
| [SoundCraft](https://github.com/storytold/soundcraft) | Аудиомонтаж, сведение, DSP, bounce | soundcraft-cli commands/run/mcp | Pre-alpha; ряд функций интерфейсов/обмена ещё развивается |
| [AniCraft](https://github.com/storytold/anicraft) | Векторная 2D-анимация, tween | CLI/MCP, последовательности кадров | Early alpha; audio layers отсутствуют по текущему README, звук сводить отдельно |

Для автоматизации читать актуальные docs/agents.md, docs/control-protocol.md, docs/cli.md/docs/mcp.md либо справку нужного проекта. Проверять бинарник, версию, список команд, короткий импорт и экспорт. Не угадывать команды и не объявлять подключение по одному README. Не устанавливать все приложения ради одного водяного знака.

[ArtCraft Studio](https://github.com/storytold/artcraft) — отдельная генеративная среда. [Официальная цена](https://getartcraft.com/pricing) описывает подписки и кредиты, а также собственный compute/сторонние подписки. Открытый клиент не означает бесплатные серверные генерации.

## Другие доступные маршруты

- Descript: Underlord и проектное редактирование; музыка/стоки зависят от возможностей сервиса и connector. [Media panel](https://help.descript.com/descript-tour/media-panel). Читать подходящие действующие инструкции.
- Runway: новые ассеты, VFX, генеративное изменение. [Edit Studio](https://help.runwayml.com/hc/en-us/articles/51683104370451-Creating-with-Edit-Studio). Проверять доступность, лимиты, стоимость. Не обещать точного восстановления исходных скрытых пикселей.
- ChatCut: использовать, только когда выбран/доступен; соблюдать собственные инструкции по импорту, проекту, слоям, проверке и экспорту.

## Медиа

- [Pexels license](https://www.pexels.com/license/): скачивание и изменение фото/видео на указанных условиях. Это стоки, не лицензированные серии аниме.
- [YouTube Audio Library](https://support.google.com/youtube/answer/3376882): музыка и эффекты через YouTube Studio; часть требует attribution. Не переносить обещания о Content ID на произвольные треки и площадки.
- Официальные каналы правообладателей: искать трейлеры/разрешённые фрагменты. Публичная ссылка не доказывает право скачивания. [YouTube Terms](https://www.youtube.com/t/terms).
- Пользовательские оригиналы: если источник закрыт или не скачивается, запросить конкретный файл/фрагмент с точным таймкодом.

Для кандидата фиксировать название/автора, URL, таймкод, качество, назначение и условия. Не выдавать найденную страницу за скачанный файл. Не обходить платные ограничения; продолжать независимую работу при недоступности одного источника.
