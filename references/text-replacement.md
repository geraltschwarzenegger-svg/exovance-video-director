# Замена текста по чистому кадру

1. Найти все появления старой надписи и точные границы отрезка. Использовать [аудит кадров](../scripts/media_audit.py) и визуальную сверку. Захватить обводку, тень и свечение.
2. Найти чистую версию той же сцены и совместить её с исходником. Для неподвижного фона подходит PNG. Для движения использовать синхронизированную дорожку чистого фона и при необходимости анимированную маску. Сверить перспективу, свет и перекрытия на нескольких кадрах.
3. Сравнить совмещённую пару кадров в небольшой области вокруг надписи. В маске белый заменяет пиксель целиком, чёрный сохраняет исходный. Если порядок движения или детали фона отличаются, поправить маску вручную. Полоса на всю ширину кадра скрывает лишние пиксели.
4. Сначала собрать PNG без нового титра и проверить, что старые буквы ушли. Потом добавить новый текст. Проверить кадры до, во время и после замены, в том числе в движении.
5. При необходимости сохранить промежуточный мастер в MKV с FFV1. Для выдачи использовать MP4 с проверкой параметров и полного декодирования. MP4 перекодирует изображение, AAC-дорожки копируются.

## Команды

Пример для одного отрезка в ролике 1920×1080. Координаты, времена, стиль и шрифт брать из конкретной сцены.

```sh
python scripts/replace_text.py mask marked.png clean.png mask.png --roi 640 780 640 180 --threshold 8 --expand 1
python scripts/replace_text.py render input.mp4 restored.png --clean-plate clean.png --mask mask.png --start 2 --end 4 --preview-at 3
python scripts/replace_text.py title title.png --size 1920 1080 --text "Новый текст" --font /path/to/font.ttf --font-size 42 --position 680 820 --stroke 2
python scripts/replace_text.py render input.mp4 master.mkv --clean-plate clean.png --mask mask.png --title-overlay title.png --start 2 --end 4
python scripts/replace_text.py render input.mp4 final.mp4 --clean-plate clean.png --mask mask.png --title-overlay title.png --start 2 --end 4
```

Для обычного титра доступна строка или многострочный текст. Для перспективы, анимации и прохода за объектом подготовить прозрачный слой в редакторе и передать его через `--title-overlay`. Видеослои должны иметь размер кадра, постоянную частоту и длительность исходника, начинаться вместе с исходником и быть совмещены до запуска. Видео маски сохранить без потерь, например в FFV1. Скрипт обрабатывает стандартные 8-битные SDR-источники.

Если чистого фона нет, детали за непрозрачными буквами придётся реконструировать. Оценивать такой результат по короткому фрагменту. Если текст закрывает лицо, меняются свет и перспектива или заметен шов, показать проблемный кадр перед выдачей.

## Документация инструментов

- [FFmpeg maskedmerge](https://ffmpeg.org/ffmpeg-filters.html#maskedmerge) используется для смешивания по значениям маски. Операция работает по пикселям.
- [Adobe Content-Aware Fill](https://helpx.adobe.com/after-effects/desktop/remove-objects-from-your-videos/content-aware-fill.html) описывает подготовку чистого референса для сложного видео. Полезно, когда фон приходится реконструировать в редакторе.
- [FFV1, RFC 9043](https://www.rfc-editor.org/rfc/rfc9043.html) описывает кодек без потерь для промежуточного мастера.
- [ProPainter](https://github.com/sczhou/ProPainter#non-commercial-use-only-declaration) оставлен справочным вариантом для видеоинпейнтинга в рамках условий проекта. Он не требуется для этого сценария.
